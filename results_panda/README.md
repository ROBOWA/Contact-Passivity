# Generated Panda evidence

These files were generated by:

```bash
python -m mujoco_panda.experiments --output results_panda
```

Each scenario/mode directory contains full-resolution `log.npz`, decimated
`log.csv`, exact `config.json`, and `metrics.json`. Scenario comparison PNGs,
the frozen-bound calibration record, whole-port sweep, governor ablation, and
the deliberately stronger 15 N stress run are included at the top level.
`acceptance.json` distinguishes passed C3 criteria from the failed small-budget
C1 whole-port criterion.

`smoothing/` contains the reproducible original-versus-revised sliding logs,
metrics, configuration snapshots, and `comparison.png`. The selected retuning
is documented in `mujoco_panda/SMOOTHING.md`.

`videos/` contains representative H.264/yuv420p replays. Regenerate them with
the commands in `mujoco_panda/README.md`.
